Snapshots & Async Fsync LLD

Two fixes for a system that has to run for days. Snapshots stop the Raft log from growing forever and make restarts take seconds instead of replaying every order ever placed. A dedicated fsync thread stops the event loop from freezing for 4 ms every time the disk flushes.

1 · Snapshot + compaction: keep the state, drop the history

2 · A follower too far behind gets the snapshot, not the history

3 · fsync on its own thread

4 · Build order and proof
