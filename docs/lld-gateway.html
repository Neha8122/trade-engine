4 · Wire protocol and risk checks

Frames: [u32 length][u8 type][fields], little-endian

Client → serverFields
LOGONclientId
NEW_ORDERclOrdId, side, type, price, qty, sendNanos
CANCELclOrdId, orderId
Server → clientFields
ACKclOrdId, orderId, sendNanos (echoed)
FILLorderId, price, qty (to maker and taker)
CANCELLEDorderId, leaves
REJECTclOrdId, reason
NOT_LEADERleaderId (or −1 if unknown)

Raft messages between nodes use the same framing: one frame per RequestVote, VoteResponse, AppendEntries or AppendResponse.

CheckRejects whenState

Rejected orders never enter the Raft log, so they cost no fsync and no replication.
