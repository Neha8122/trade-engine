Market Data Feed LLD

How the whole market learns what the book did: every add, fill and cancel is encoded into a few bytes, packed into UDP packets, multicast to every subscriber, and rebuilt into an identical book on the other side, even when packets get lost.

4 · Decisions

DecisionChosenWhy
Separate public eventsnew BookListener (add, execute, delete) next to ExecutionListenermarket data must not reveal client ids, and an IOC leftover that never rested must not appear as a delete. The book knows exactly when an order rests, fills or leaves, so it reports that directly
Per-order messages (L3)add / execute / delete per ordersubscribers can rebuild the exact book, queue position included; price-level totals can always be derived from it
Encodingfixed-layout binary, little-endianno parsing, no strings, no allocation; ~10× smaller than JSON
TransportUDP multicast behind a PacketSink interfaceone send reaches every subscriber; the interface lets tests use a fake network that drops and duplicates packets on purpose
Flushwhen the next message wouldn't fit, or when the engine finishes a batchfull packets for throughput, no message waits for more traffic to arrive
Recoveryretransmit store: a byte ring of the last N messagesa small gap is fixed in microseconds; only a long outage needs a full snapshot (later)
Scope for week 4one symbol per feedsymbolId joins the messages when the engine runs many books

5 · Classes and how we'll prove it works

// orderbook: new public-event interface
interface BookListener {
  void onAdd(long orderId, Side side, long price, long qty);
  void onExecute(long orderId, long qty, long price);
  void onDelete(long orderId);
}

// feed module
final class MarketDataPublisher implements BookListener
final class Packetizer        // header + messages, flush()
interface   PacketSink        { void send(ByteBuffer packet); }
final class UdpPacketSink implements PacketSink
final class RetransmitStore   // last N messages by seqNo
final class FeedHandler       // seq checks, gap recovery
final class BookReplica       // subscriber's copy of the book
final class Codec             // offsets + encode/decode
