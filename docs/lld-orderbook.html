3 · What happens when a new order arrives

Cancel is simpler

  1. order = index.get(orderId). If it's null (unknown or already filled), send onRejected(UNKNOWN_ORDER) and stop.
  2. order.level.remove(order): relink prev and next, lower totalQty. O(1), no searching.
  3. If that level is now empty and it was the best, move bestBid or bestAsk to the next non-empty level.
  4. index.remove(orderId), pool.release(order), onCancelled(orderId, leaves).

Patterns to name in the interview

Object poolOrderPool, so there's no garbage and no GC pause
ObserverExecutionListener, which keeps the book free of I/O. Events take primitive arguments, so no event objects are created
Intrusive listprev/next live inside Order, so no list nodes
Single writerone thread owns the book, so no locks anywhere in this module

Out of scope for week 1: self-trade prevention, order modify, multiple symbols in one test.
